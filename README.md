# SocialHub - Social Media Platform
A full-stack social media web application built with Django, designed to provide an interactive platform for users to connect, share content, and engage with others. The platform features user authentication, profile management, post creation, likes, comments, and follow/unfollow functionality, delivering a seamless social networking experience.

## Key Features

- User registration, login, and authentication
- User profile creation and management
- Create and share social media posts
- Like and unlike posts
- Comment and interact with posts
- Follow and unfollow other users
- Individual user profiles with published posts
- Image uploads for social media content
- Dynamic interactions using AJAX
- Responsive and user-friendly interface
- Database integration for user and content management
- Django-powered backend architecture

## Technology Stack

- **Backend:** Django (Python)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Dynamic Interactions:** AJAX
- **Version Control:** Git & GitHub

## Project Objective

This project demonstrates the development of a modern social networking platform while applying full-stack web development principles, user authentication, database management, and dynamic backend integration using Django. It showcases practical skills in building interactive web applications, managing user-generated content, and implementing social networking functionalities with a user-centric design approach.
